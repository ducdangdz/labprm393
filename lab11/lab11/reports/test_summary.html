3. Test Architecture & Design Principles

  • AAA Pattern (Arrange → Act → Assert): Every test file clearly segregates the setup state, action execution, and assertion validation.
  • Explicit Key Finding: Widgets are targeted with robust Key identifiers (e.g. Key('taskInputField'), Key('addTaskButton'), Key('detailTitleField'), Key('saveTaskButton')) to prevent brittle UI tests.
  • Asynchronous Pump Control: Uses pump() for immediate frame updates and pumpAndSettle() for full routing and transition completion.

4. Known Limitations & Future Roadmap

  1. Persistence: In-memory repository clears on app restart; future versions will integrate SQLite or Hive.
  2. Offline Sync: No remote sync mechanism is currently implemented in this module.
  3. Soft Deletes: Tasks are hard-deleted immediately; future versions can include an undo snackbar.
